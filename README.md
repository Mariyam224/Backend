## ⚙️ Getting Started

To explore and run the code examples locally:

**1. Clone the repository**

```bash
git clone https://github.com/Mariyam224/Backend.git
```

**2. Navigate to the repository**

```bash
cd Backend
```

**3. Open the project in VS Code**

```bash
code .
```

**4. Run the JavaScript files**

Navigate to the relevant topic folder and execute the required file:

```bash
node filename.js
```

Make sure Node.js is installed on your system.

If a particular folder contains a `package.json`, install its dependencies before running the examples.
