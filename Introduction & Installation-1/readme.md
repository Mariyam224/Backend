# Commands -:

From this file, we will going to learn javascript from the backend.

Whenver we create a backend project, we use node.js for the same.

1) node --version = to check the exact version of Node.js currently active on your system. 

2) npm --version = to display the currently installed version of the Node Package Manager (npm) on your system.

3) npm init = command initializes a new Node.js project by creating a package.json file in your current working directory. 

4) npm init -y (or --yes) = instantly initailizes a new Node.js project by creating a package.json file in your current working directory without any prior questionaire.

- NPM (Node Package Manager) is the default package manager for the JavaScript runtime environment for Node.js. 

5) npm install <package-name> =  is a command-line instruction used in Node.js projects to download and install external code libraries (called "packages" or "dependencies").

- e.g. npm install slugify  (used in this project; created a node_modules folder in the directory)

- package dependencies can be dependent on further packages.

# Difference between npm init and npm init -y (or --yes)-:  

> Interaction: npm init opens an interactive wizard; npm init -y skips it entirely.

> Input: npm init requires you to answer or accept 9+ prompts; npm init -y automatically says "yes" to all of them.

> Values: npm init lets you customize project details upfront; npm init -y uses strict default settings based on your folder name.

> Speed: npm init takes a few moments to complete; npm init -y generates the package.json file instantly.Best For: npm init is for formal, public packages; npm init -y is for fast local prototyping and tutorials.
